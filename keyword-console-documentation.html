1. Overview

lewisiii Keyword Console is an internal, web-based keyword research dashboard built and used exclusively by lewisiii studio. The studio researches search demand and builds its own content websites and small web utilities. The console's sole purpose is to query the Google Ads API for keyword metrics (search volume, competition, bid ranges) so we can plan and evaluate our own content properties.

The tool is not sold, licensed, or distributed to any third party. It has no mobile application and is not listed on the Google Play Store or Apple App Store; it runs as a private web application on our internal workstation.
