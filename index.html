What we build

Single-purpose browser tools — converters, generators, formatters — designed to answer one question instantly, with no sign-up required.

Reference & content sites

Search research

Ongoing keyword and market research using Google Keyword Planner and public search data to identify underserved needs.

Our application

lewisiii studio Console

lewisiii studio Console is our internal web dashboard. It uses official Google APIs — the Google Search Console API, Google Analytics Data API, and Google Ads API — to help our team research keywords (search volume and competition) and monitor the search performance of our own websites. The application is used only by lewisiii studio staff, only for properties we own, and is not offered to the public. Data obtained through Google APIs is stored securely, never resold, and never shared with third parties.
